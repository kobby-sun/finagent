# FIN-024 — Segregation of duties: vendor creator tries to approve

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-003 s1, FIN-POL-001 s4

## Signals

u-dd-02 created the vendor record and may not approve its invoices.

## Request

```json
{
  "case_id": "FIN-024",
  "invoice_ref": "MC-2024",
  "vendor_id": "V-1013",
  "amount": "22000.00",
  "currency": "AUD",
  "po_ref": "PO-40024",
  "requester_id": "u-req-11"
}
```

Attachments: `MC-2024.json` (application/json, source=supplier) — see `mock_data/cases/FIN-024/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "APPROVE_FOR_POSTING",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`
2. `APPROVE` by `u-dd-02` -> HTTP 403, run `AWAITING_APPROVAL`
3. `APPROVE` by `u-dd-01` -> HTTP 200, run `COMPLETED`

## Run it

```bash
finagent start --case FIN-024
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-024
```
