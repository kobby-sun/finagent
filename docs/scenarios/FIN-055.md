2. `APPROVE` by `u-ap-01` -> HTTP 403, run `AWAITING_APPROVAL`
3. `REJECT` by `u-ccm-01` (callback `r-1`) -> HTTP 200, run `COMPLETED`
4. `REJECT` by `u-ccm-01` (callback `r-1`) -> HTTP 200, run `COMPLETED` (replayed response)
5. `APPROVE` by `u-dd-01` (callback `late-1`) -> HTTP 409, run `COMPLETED`
6. Check exit_node=FINALIZE_REJECTED, tools_not_called=['submit_finance_decision'], audit_events=['approval.denied:forbidden', 'approval.callback_replayed', 'approval.duplicate_ignored:conflict'], webhooks=['approval.resolved', 'run.completed'], no_webhooks=['decision.submitted'], reasoning=[{'step': 'HUMAN_DECISION', 'actor': 'human:u-ap-01', 'contains': 'REFUSED'}, {'step': 'HUMAN_DECISION', 'actor': 'human:u-ccm-01', 'contains': 'REJECT'}]
