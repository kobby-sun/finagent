# FIN-034 — First payment after a verified bank change

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-004 s2, FIN-POL-003 s3

## Signals

Bank change 2026-10-20 verified and past the hold; first payment needs Financial Control co-approval.

## Request

```json
{
  "case_id": "FIN-034",
  "invoice_ref": "PF-1100",
  "vendor_id": "V-1016",
  "amount": "4400.00",
  "currency": "AUD",
  "po_ref": "PO-40034",
  "requester_id": "u-req-11"
}
```

Attachments: `PF-1100.json` (application/json, source=supplier) — see `mock_data/cases/FIN-034/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "APPROVE_FOR_POSTING",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`<br/>&nbsp;&nbsp;- slots: `['primary', 'financial_control']`
2. `APPROVE` by `u-fc-02` -> HTTP 200, run `AWAITING_APPROVAL`
3. `APPROVE` by `u-ccm-01` -> HTTP 200, run `COMPLETED`

## Run it

```bash
finagent start --case FIN-034
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-034
```
