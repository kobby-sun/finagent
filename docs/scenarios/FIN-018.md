# FIN-018 — High value requires CFO (current matrix, not superseded)

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-003 s2, FIN-POL-003-OLD (superseded)

## Signals

AUD 330,000 > Executive Director limit 250,000 (v4.0). The superseded v1.0 matrix must not be used.

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`<br/>&nbsp;&nbsp;- required_role: `Chief Financial Officer`<br/>&nbsp;&nbsp;- not_cited: `['FIN-POL-003-OLD']`
2. `APPROVE` by `u-ed-01` -> HTTP 403, run `AWAITING_APPROVAL`
3. `APPROVE` by `u-cfo-01` -> HTTP 200, run `COMPLETED`
