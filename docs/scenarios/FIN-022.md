# FIN-022 — Application restart / resume (crash mid-graph and after submit)

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** (reliability)

## Signals

Process crashes after RECONCILE, and again after SUBMIT_DECISION; resume must not double-submit.

## Request

```json
{
  "case_id": "FIN-022",
  "invoice_ref": "RS-4480",
  "vendor_id": "V-1018",
  "amount": "3300.00",
  "currency": "AUD",
  "po_ref": "PO-40022",
  "requester_id": "u-req-11"
}
```

Attachments: `RS-4480.json` (application/json, source=supplier) — see `mock_data/cases/FIN-022/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "APPROVE_FOR_POSTING",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run (simulate crash after RECONCILE) -> expect `RUNNING`
2. Resume run -> `AWAITING_APPROVAL`
3. `APPROVE` by `u-ccm-01` (simulate crash after SUBMIT_DECISION) -> HTTP 200, run `RUNNING`
4. Resume run -> `COMPLETED`
5. Resume run -> `COMPLETED`
6. Assert erp_decisions=1

## Run it

```bash
finagent start --case FIN-022
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-022
```
