**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-003 s3

## Signals

Vendor created 13 days ago: higher-risk => primary approver + Financial Control.


## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`<br/>&nbsp;&nbsp;- slots: `['primary', 'financial_control']`
2. `APPROVE` by `u-ccm-01` -> HTTP 200, run `AWAITING_APPROVAL`
3. `APPROVE` by `u-ccm-01` -> HTTP 200, run `AWAITING_APPROVAL`
4. `APPROVE` by `u-fc-01` -> HTTP 200, run `COMPLETED`

## Run it

```bash
finagent start --case FIN-012
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-012
```
