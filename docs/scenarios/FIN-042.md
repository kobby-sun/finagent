# FIN-042 — PDF invoice (binary attachment, text extraction)

**Kind:** edge  |  **Input format:** PDF (base64)  |  **Policies:** FIN-POL-001 s2

## Signals

Supplier sends a PDF; text is extracted (pypdf) and parsed through the same contract.

## Request

```json
{
  "case_id": "FIN-042",
  "invoice_ref": "RS-4510",
  "vendor_id": "V-1018",
  "amount": "3850.00",
  "currency": "AUD",
  "po_ref": "PO-40042",
  "requester_id": "u-req-11"
}
```

Attachments: `RS-4510.pdf` (application/pdf, source=supplier) — see `mock_data/cases/FIN-042/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "APPROVE_FOR_POSTING",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`
2. `APPROVE` by `u-ccm-01` -> HTTP 200, run `COMPLETED`

## Run it

```bash
finagent start --case FIN-042
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-042
```
