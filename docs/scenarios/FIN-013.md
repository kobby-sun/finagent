# FIN-013 — Foreign currency (USD) with overseas bank

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-009 s2-s4, FIN-POL-003 s3

## Signals

USD invoice on USD PO; authority assessed in AUD at corporate rate 1.5200; overseas account => Financial Control.

## Request

```json
{
  "case_id": "FIN-013",
  "invoice_ref": "II-77001",
  "vendor_id": "V-1009",
  "amount": "10000.00",
  "currency": "USD",
  "po_ref": "PO-40013",
  "requester_id": "u-req-11"
}
```

Attachments: `II-77001.json` (application/json, source=supplier) — see `mock_data/cases/FIN-013/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "APPROVE_FOR_POSTING",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `APPROVE_FOR_POSTING`<br/>&nbsp;&nbsp;- amount_aud: `15200.00`<br/>&nbsp;&nbsp;- slots: `['primary', 'financial_control']`
2. `APPROVE` by `u-ccm-01` -> HTTP 403, run `AWAITING_APPROVAL`
3. `APPROVE` by `u-dd-01` -> HTTP 200, run `AWAITING_APPROVAL`
4. `APPROVE` by `u-fc-02` -> HTTP 200, run `COMPLETED`

## Run it

```bash
finagent start --case FIN-013
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-013
```
