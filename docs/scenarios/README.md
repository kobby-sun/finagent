Required cases from the brief are FIN-001..FIN-005, `edge` cases cover single edge conditions, and `combined` cases (FIN-043+) stack several edge conditions at once. The mock clock is frozen at `2026-11-12T10:00:00+11:00`.

**Every scenario is checked for:**
- outcome, status and primary exception;
- the step the workflow **exits** at (and steps it must never reach);
- tools that must or must not be called;
- required audit events (retries, model guard, approval refusals, replays);
- exceptions, warnings (risk indicators) and unknowns that must be recorded;
- reasoning-trace entries and emitted webhooks.

**Global invariants applied to all scenarios:** the exit step matches the status; held or escalated cases never create an approval or call the posting tool; every executed control has a reasoning entry; no untrusted or superseded policy is cited; no full bank account number appears in the audit log. `finagent eval --diagrams png` draws each scenario's final run.
