# FIN-033 — Invoice addressed to another legal entity

**Kind:** edge  |  **Input format:** e-invoice JSON  |  **Policies:** FIN-POL-001 s1

## Signals

Bill-to is not a Northstar entity -> REJECT_INVALID (approval-gated).

## Request

```json
{
  "case_id": "FIN-033",
  "invoice_ref": "INV-AC-7870",
  "vendor_id": "V-1001",
  "amount": "1100.00",
  "currency": "AUD",
  "po_ref": "PO-40033",
  "requester_id": "u-req-11"
}
```

Attachments: `INV-AC-7870.json` (application/json, source=supplier) — see `mock_data/cases/FIN-033/attachments/`.

## Expected control behaviour

```json
{
  "status": "COMPLETED",
  "outcome": "REJECT_INVALID",
  "pool_status": "SUBMITTED",
  "erp_decisions": 1
}
```

## Steps

1. Start run -> expect `AWAITING_APPROVAL`, outcome `REJECT_INVALID`
2. `APPROVE` by `u-ccm-01` -> HTTP 200, run `COMPLETED`
3. Assert erp_decision_verb=REJECT

## Run it

```bash
finagent start --case FIN-033
finagent approvals --status PENDING --explain   # if awaiting approval
finagent approve <approval_id> --approver <user> --callback-id <id>
finagent eval --cases FIN-033
```
