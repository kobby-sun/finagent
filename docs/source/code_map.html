finagent code map: what each file does and how they relate

All runtime code is in src/finagent/. Arrows point from the user to the used. Purple = talks to an LLM (only llm/providers.py makes the network call).

1 entry points build all components once, through services.py, which runs the start-up checks 7 llm_runner.py sends skill questions to the small / large model
2 services.py creates the Engine and gives it store, audit, tools, models, plan 8 baseline.py compares the indexed policy text with the verified baseline
3 entry points start, approve, review and resume runs on the Engine 9 the retrieve_docs tool runs the hybrid policy search
4 PARSE_INPUTS and RECONCILE: parsers, control scripts, skill questions 10 controls read policy numbers from params.py (config/policy_parameters.yaml)
5 DRAFT: narrative prompt and checks in drafting.py 11 every file uses the foundation: types, settings, SQLite store, audit log
6 GATHER_EVIDENCE and SUBMIT: every external call goes through the tool runtime Policy changes are maintenance releases: nothing reloads while running
